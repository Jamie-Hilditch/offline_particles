# Generated documentation sources

This directory is written entirely by the Sphinx build — nothing here is
hand-edited.

- `api/` — autosummary stubs generated from `api.md`'s `:toctree:` directive.
- `gallery/` — sphinx-gallery output generated from `examples/` scripts (see
  `examples.md`).

Both subdirectories are gitignored; only this README is tracked, so the
directory still shows up (and explains itself) in a fresh checkout.
